Catalog

How publishing works. Everything is entered as links — thumbnail, video parts and photos. A new title is saved at the top of the catalog, so the latest upload appears first. Edits are saved in this browser immediately for preview; click Publish live to send the catalog to the site, and every page picks it up on the next load without a redeploy. Copy/Download stay available as offline backups. The lock screen and publish code are client-side screens, not server security, so keep admin.html out of search results and casual hands.

Where these numbers come from. Every playback session reports to the CDN Worker, which stores one row per view and counts forward watch time only — up to what the session could really have played. The Views field in the clip editor is a separate, human-entered number that visitors see on the site; use the button above to copy measured views into it when you want them to match.
